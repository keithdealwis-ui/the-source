# The Source: Open Source Alternatives (Chrome extension)

A deliberately thin client of The Source's read surface (`../api/v1/`, see
[`docs/READ-API.md`](../docs/READ-API.md)). On a supported SaaS site the toolbar icon
shows a seedling with the number of credible open-source alternatives. Clicking it
opens a panel with 3–5 recommendations. No popups, no account, no AI chat.

Built for KEI-808.

## What the panel shows

For each recommendation: project name (linked to GitHub), Replacement Fit (0–100),
GitHub stars, maintenance status (Active / Maintained), licence (SPDX), self-hosting
("Self-hostable" only with evidence), and the machine-derived best-fit/gap note,
labelled "(auto-summary)". Under the list is a "Compare" link to
`de-alwis.com/open-source/<product>-alternatives`. The footer shows when GitHub data
was last checked.

| State | Behaviour |
|---|---|
| Supported product, 3–5 recommendations | The list. |
| Supported product, 1–2 recommendations | What there is, with "Only N credible alternatives right now". Never padded. |
| Supported product, none | Says so; the Compare link remains. |
| Not a supported site | "No open-source alternatives tracked for this site" plus the product list. The icon stays grey. |
| Offline or a refresh failed, with a saved copy | The saved copy, with a notice. |
| Data more than 14 days old | A staleness notice. |
| First run offline, nothing saved | An error with "Try again". |

## Data

The extension bundles no data. The service worker downloads the whole read surface
(`index.json`, `domains.json` and every `saas/<id>.json`, about 170 KB) on install, at
browser start if more than 6 hours old, and every 6 hours. It uses
`raw.githubusercontent.com/keithdealwis-ui/the-source/main/api/v1/`, falling back to
the jsDelivr mirror. A snapshot is accepted only when every file arrived and all carry
the same `dataset_version`; otherwise the last good copy stays. Adding a product to
`config/supported_saas.yaml` needs no extension release: the next refresh picks up
its rules.

## Permissions

| Permission | Install warning | Use |
|---|---|---|
| `declarativeContent` | none | Chrome matches supported sites itself (rules from `domains.json`) and swaps the toolbar icon. The extension is never told which page is open. |
| `activeTab` | none | On an icon click, read that tab's URL once to pick the product. Not stored or sent. |
| `storage` | none | The cached read surface and last-refresh status. |
| `alarms` | none | The 6-hourly refresh. |

No host permissions, no content scripts, no `tabs`, `history` or `webNavigation`. The
CSP limits network access to the two read-surface origins. `test/manifest.test.mjs`
enforces all of this.

## Privacy

See [`PRIVACY.md`](PRIVACY.md), which is also the store privacy policy. No analytics
of any kind in 0.1.0.

## Layout

```text
manifest.json
src/match.js        URL → product, and the equivalent declarativeContent filters
src/data.js         fetch, validate and cache the read surface
src/view.js         what the panel shows, as plain data
src/background.js   service worker: refresh schedule, detection rules, icon
popup/              the panel
icons/              generated by scripts/make-icons.mjs
store/              Chrome Web Store listing copy and screenshots
test/               Node unit tests (no dependencies)
scripts/            icons, end-to-end run in Chromium, packaging
```

## Develop

```bash
cd extension
npm test                       # unit tests, Node 20+, no install needed
npm install                    # playwright-core, for the scripts below
npm run e2e                    # loads the unpacked extension in Chromium
npm run package                # dist/the-source-extension-<version>.zip
```

The scripts use the Chromium that playwright-core resolves, or `CHROMIUM_PATH`.
To try it by hand: `chrome://extensions`, Developer mode, "Load unpacked", pick this
folder, then visit e.g. `https://trello.com/`.

## Release

`npm run package` builds the zip for the Chrome Web Store. Submission, the developer
account and publishing are Keith's decision. `store/LISTING.md` holds the listing copy,
permission justifications and privacy answers.
