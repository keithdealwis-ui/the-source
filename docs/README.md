# The Source documentation

Discover software, follow emerging projects, find open-source alternatives and bring the evidence into your workflow.

## Start using The Source

| What you want to do | Where to go |
|---|---|
| Find alternatives to a product | [Explore the website](https://the-source.dev/#explore) |
| See what is breaking out or surging | [Explore the momentum radar](https://the-source.dev/#radar) |
| Compare projects or check their health | [Connect an AI assistant](https://the-source.dev/agents/#setup) and use the [MCP examples](MCP.md#more-ways-to-use-it) |
| Ask through an AI assistant | [Choose your client](https://the-source.dev/agents/#setup) or [read the MCP guide](MCP.md) |
| Build an integration | [Read API](READ-API.md) |
| Suggest a project or correct a fact | [Contribution guide](../CONTRIBUTING.md) |
| Get help | [Support](https://the-source.dev/support/) |
