# Historical engineering records

These records document earlier implementation, acceptance checks and design decisions. Their dates, counts, endpoints, release states and pending actions describe that work. They are not current product instructions.

- [Acceptance records](acceptance/): implementation criteria and verification evidence.
- [Decision records](decisions/): dated research, launch policy and edition-check results.

The original paths retain pointers for incoming links. Current reader and developer guides are in the [documentation index](../README.md).
